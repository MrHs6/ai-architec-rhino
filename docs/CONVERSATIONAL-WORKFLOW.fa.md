# ساخت، توضیح و ادامهٔ ویرایش در همان سند

## نمونهٔ قابل آزمون بدون کلید

در Generate بنویسید:

```text
Create a 15 x 20 meter building with 5 floors and 3.2 meter floor heights.
```

پیش‌نمایش را بررسی کنید و **Apply to Rhino** را بزنید. خروجی نمونه ۴۶ جزء بومی راینو دارد. چت پس از Apply تعداد اجزا، ابعاد واقعی و اطلاعات طبقات را گزارش می‌کند. این پاسخ بازخوانی هندسه است؛ ادعای خروجی مدل آنلاین نیست.

برای ادامه، **Refine result** را انتخاب کنید، یا در Generate یک ویرایش روشن بنویسید:

```text
طبقه‌ی پنجم ساختمان را ۲ متر عقب جابه‌جا کن
```

فرمان به Assist و محدودهٔ Recent result هدایت می‌شود. در این نمونه «عقب» یعنی محور جهانی +Y و این فرض در پیش‌نمایش نوشته می‌شود. فقط اجزای دارای اطلاعات طبقهٔ پنجم هدف قرار می‌گیرند؛ Apply همان GUIDها را نگه می‌دارد و اجزای سایر طبقات را جابه‌جا نمی‌کند.

برای جهت بدون ابهام می‌توانید بنویسید:

```text
Move floor 5 by 2 meters along Y.
```

با **Ctrl+Z** مرحله را برگردانید. چت تغییر واقعی روی نتیجه را تشخیص می‌دهد و اندازه‌گیری را تازه می‌کند. دکمهٔ Select خروجی اخیر را انتخاب می‌کند؛ Explain آن را دوباره می‌سنجد. اگر خروجی حذف یا Undo شده باشد، ویرایش روی اشیای گمشده انجام نمی‌شود.

## اتصال و ذخیرهٔ API

1. در API profiles سرویس واقعی کلید را انتخاب کنید؛ کلید OpenAI با انتخاب OpenRouter یکی نیست.
2. کلید را داخل پلاگین وارد کنید. برای ماندن پس از خروج راینو، Remember را فعال کنید؛ در حالت خاموش کلید فقط در همان اجرای راینو باقی می‌ماند.
3. Save پروفایل را فعال می‌کند و Connect پیش از درخواست شبکه آن را ذخیره می‌کند. نتیجهٔ ذخیره در پیام مستقل نمایش داده می‌شود.
4. Connect فهرست مدل‌ها را می‌گیرد. مدل را انتخاب کنید و به محیط کار برگردید.
5. اگر اتصال شکست خورد، Test network را اجرا کنید. این آزمون کلید یا هندسه را ارسال نمی‌کند. HTTP 401 در این آزمون نشان‌دهندهٔ پاسخ‌دادن میزبان است، نه ردشدن کلیدی که هنوز ارسال نشده است.

OpenAI مستقیم از Responses API و قالب JSON schema استفاده می‌کند؛ سرویس‌های سازگار از Chat Completions استفاده می‌کنند. مدل یا سرویس بدون اطلاع کاربر تعویض نمی‌شود. هزینهٔ درخواست‌های تولید آنلاین متعلق به حساب ارائه‌دهندهٔ خود کاربر است.

در این نسخه، ورودی‌های آزاد و تحلیل مرجع به مدل آنلاین سازگار نیاز دارند. حالت آفلاین یک پارسر نمونهٔ محدود برای ساختمان مستطیلی، باکس و جابه‌جاییِ صریح است. تاریخچه و شناسهٔ نتیجه به هر سند و نشست بازِ راینو تعلق دارند.
