# اتصال سادهٔ MCP — نسخهٔ 0.4.2

رابط پلاگین و راهنمای داخل آن انگلیسی است؛ می‌توانید فارسی پرامپت بدهید.

## چت در Codex یا Claude Desktop

1. داخل راینو فرمان **archtec** را اجرا و صفحهٔ **MCP connection** را باز کنید.
2. کلاینت **Codex** یا **Claude Desktop** را انتخاب و **Connect to Codex/Claude Desktop** را بزنید. پلاگین سرور محلی را روشن، مسیر پل نصب‌شده را در تنظیمات همین کاربر ثبت و برنامهٔ کلاینت را در صورت یافتن باز می‌کند. در مسیر عادی نیازی به کپی هیچ متن نیست.
3. فقط در اولین نصب یا ارتقای پلاگین، اگر Codex از قبل باز است، از **Settings → Plugins → MCPs** آیکون refresh کنار Servers را بزنید یا کلاینت را دوباره باز کنید. Claude Desktop بعد از تغییر تنظیمات باید کامل بسته و دوباره اجرا شود. مجوز ابزارها را در صورت درخواست کلاینت تأیید کنید.
4. گفتگو را در همان کلاینت انجام دهید. از آن بخواهید با سرور **ai-architec-rhino** ابزار **get_context** را اجرا کند. وضعیت پنل بعد از تماس واقعی به **Connected · Codex/Claude Desktop** می‌رسد.
5. درخواست مدل‌سازی بدهید، پیش‌نمایش را در راینو بررسی و **Apply to Rhino** را بزنید. کلاینت با **get_plan_status** نتیجه را می‌خواند و با **post_message** توضیح را به پنل برمی‌گرداند.

در مسیر **MCP · chat in your AI client** کادر چت داخل راینو مخفی است؛ اینجا محل پیش‌نمایش، Apply و دیدن نتیجه است. مرجع تصویری را در کلاینت ضمیمه کنید. برای چت مستقیم داخل راینو مسیر **Chat here · API / offline tools** و پروفایل API شخصی را انتخاب کنید.

## قطع و وصل دوباره

کلاینت را باز نگه دارید؛ در راینو دوباره Connect را بزنید. پل جدید نشست و توکن جدید را خودکار پیدا می‌کند. برای خاموش‌و‌روشن‌کردن MCP راینو، Reload کلاینت یا کپی تنظیمات لازم نیست. درخواست هنگام خاموشی، پیام خطای روشن می‌دهد و پل را نمی‌بندد. بعد از اتصال دوباره ابتدا get_context را امتحان کنید. درخواست مدل‌سازیِ ناموفق یا زمان‌تمام‌شده خودکار تکرار نمی‌شود؛ پیش‌نمایش و وضعیت درخواست قبلی را بررسی کنید تا خروجی تکراری نسازید.

ارتقای خود پلاگین مسیر فایل پل را عوض می‌کند؛ پس از ارتقا یک‌بار Connect و refresh کلاینت لازم است. نام کلاینت اطلاعات اعلام‌شدهٔ پروتکل است و به‌معنی تأیید ورود به حساب نیست.

## تنظیمات دستی

بخش بستهٔ **Manual setup and diagnostics** برای کلاینت‌های دیگر یا شکست ثبت خودکار است. **Copy configuration** فقط برای تنظیمات کلاینت است؛ **Copy connection-test prompt** فقط متن یک پیام آزمایشی بعد از ثبت سرور است. ارسال تنظیمات در چت، اتصال ایجاد نمی‌کند.

ثبت Codex از CLI رسمی codex mcp add استفاده می‌کند. تنظیم Claude فقط ورودی ai-architec-rhino را در فایل تنظیمات همان کاربر ادغام می‌کند؛ تنظیمات دیگر حفظ و نسخهٔ پشتیبان .architec-backup ساخته می‌شود. برنامه‌ها و ورود به حساب باید قبلاً توسط کاربر انجام شده باشد. هیچ API Key یا توکن نشست در تنظیمات صادرشده قرار نمی‌گیرد. تنظیم قدیمی دارای ARCHITEC_MCP_TOKEN را با تنظیم جدید جایگزین کنید.

پورت پیش‌فرض 5188 است. روی دو رایانه استفاده از همین پورت مشکلی ندارد؛ دو نشست هم‌زمان روی یک رایانه به پورت‌های متفاوت و ورودی‌های مجزای کلاینت نیاز دارند.

## ChatGPT در مرورگر

بازکردن سایت، پل محلی را ثبت نمی‌کند. مسیر ابری به connector یا Secure MCP Tunnel پشتیبانی‌شده و تنظیم حساب نیاز دارد. این نسخه تونل عمومی، OAuth یا ارسال خودکار پیام به مرورگر راه‌اندازی نمی‌کند. برای مسیر ساده از Codex/Claude محلی، و برای چت در پنل از API شخصی استفاده کنید.

## بخش‌ها

- **Generate:** ایجاد هندسهٔ جدید، پیش‌نمایش و Apply. در مسیر API گزینهٔ نما و لایه در راینو است؛ در MCP کلاینت طرح را تعیین می‌کند.
- **Analyze:** گزارش محلی ابعاد، سلامت هندسه و لایه‌های انتخاب یا خروجی اخیر، بدون تغییر مدل. تحلیل مهندسی نیست.
- **Assist:** تغییر انتخاب یا خروجی اخیر؛ Move با فاصله/محور، Scale با ضریب و Extrude با ارتفاع. پیش‌نمایش را بررسی کنید؛ Ctrl+Z عملیات اجراشده را برمی‌گرداند.
