# اتصال MCP و گفت‌وگو در آرشتک

## دو مسیر متفاوت

**چت داخل پلاگین:** در API profiles سرویس، کلید شخصی و مدل را متصل کنید؛ مسیر چت را روی `Chat here · API / offline tools` نگه دارید. روشن‌کردن MCP به‌تنهایی این چت را به اشتراک ChatGPT یا Claude وصل نمی‌کند. بدون API، این مسیر فقط مثال‌های محدود هندسی و گزارش محلی دارد.

**گفت‌وگو در کلاینت MCP:** Claude Desktop یا Codex محلی ابزارهای آرشتک را دریافت می‌کند؛ شما در آن برنامه صحبت می‌کنید. کلاینت با `post_message` پاسخ را در پنل نمایش می‌دهد یا با `propose_plan` پیش‌نمایش می‌سازد. اعمال هندسه همچنان با Apply داخل راینو انجام می‌شود.

## راه‌اندازی

1. در راینو `archtec` را اجرا و MCP connection را باز کنید. Start localhost MCP را بزنید؛ وضعیت ابتدا «منتظر کلاینت» است.
2. کلاینت را انتخاب کنید. برای Claude Desktop خروجی JSON و برای Codex خروجی TOML داده می‌شود. آن را در **تنظیمات برنامه** ثبت کنید؛ فرستادن تنظیمات در متن چت اتصال ایجاد نمی‌کند. سایر ورودی‌های تنظیمات را حذف نکنید.
3. Claude Desktop: Settings → Developer → Edit Config، سپس ادغام ورودی `ai-architec-rhino` در بخش `mcpServers` فایل `%APPDATA%\Claude\claude_desktop_config.json`. Claude را کامل ببندید و دوباره اجرا کنید. [راهنمای رسمی کلاینت محلی](https://modelcontextprotocol.io/docs/develop/connect-local-servers)
4. Codex: در تنظیمات MCP، یک ورودی STDIO با نام `ai-architec-rhino`، مسیر `command` و متغیر `ARCHITEC_MCP_PORT` بسازید؛ یا قطعهٔ TOML را به `~/.codex/config.toml` اضافه کنید. اتصال را Reload کنید. در CLI، `codex mcp list` تنظیمات و `/mcp` وضعیت ابزارها را نشان می‌دهد. نام منوها ممکن است با نسخهٔ کلاینت فرق داشته باشد. [راهنمای رسمی MCP](https://learn.chatgpt.com/docs/extend/mcp?surface=cli)
5. **Copy a connection-test prompt** را بزنید و متن را در چت کلاینت ارسال کنید. کلاینت باید ابزار **ai-architec-rhino** را به کار ببرد؛ سرور دیگری مثل `rhino-mcp-router` مسیر جداگانه‌ای است.
6. پس از initialize نام اعلام‌شدهٔ کلاینت و زمان آخرین تماس در پنل دیده می‌شود. tools/list بارگیری ابزارها و get_context خواندن سند را تأیید می‌کنند. روشن‌بودن سرور یا بازشدن یک سایت، تأیید اتصال نیست.

پل نصب‌شده توکن جاری را از فایل کشف نشست با رمزگذاری Windows DPAPI می‌خواند. خروجی جدید تنظیمات شامل توکن نیست. بعد از Stop/Start سرور، کلاینت را Reload کنید تا پل نشست تازه را بخواند؛ لازم نیست توکن تازه را کپی کنید. تنظیم قدیمیِ دارای `ARCHITEC_MCP_TOKEN` را با خروجی جدید جایگزین کنید. این فایل کشف به همان حساب ویندوز محدود است و با توقف عادی MCP پاک می‌شود.

## نمونهٔ گفت‌وگو و برگشت پاسخ

در چت کلاینت بنویسید:

> با سرور ai-architec-rhino، ابتدا get_context را بخوان. با post_message در بخش generate تأیید کن که سند را دیده‌ای؛ فعلاً هندسه را تغییر نده.

سپس برای ساخت:

> یک ساختمان ۱۵ در ۲۰ متر، پنج طبقه با ارتفاع طبقات ۳٫۲ متر پیشنهاد بده. فقط پیش‌نمایش بساز. پس از Apply من، get_plan_status را بخوان و نتیجهٔ تأییدشده را با post_message توضیح بده.

اگر می‌خواهید متن را در پنل راینو بنویسید، مسیر چت را روی `MCP client · copy request to Claude / Codex` بگذارید و Generate/Analyze/Assist را بزنید. متن برای کلاینت کپی می‌شود؛ در چت کلاینت Paste و ارسال کنید. در این مرحله ارسال خودکار به حساب یا تب مرورگر انجام نمی‌شود. تصویر مرجع را مستقیماً در کلاینت ضمیمه کنید.

## مراحل وضعیت

| وضعیت | معنی |
|---|---|
| سرور خاموش | Start لازم است |
| منتظر کلاینت | آدرس محلی باز است؛ کلاینت هنوز initialize نکرده |
| کلاینت شناسایی شد | نام اعلام‌شده در initialize دریافت شده؛ این احراز هویت حساب نیست |
| ابزارها معرفی شدند | tools/list موفق بوده |
| زمینهٔ سند پاسخ داده شد | get_context به سند دسترسی داشته |
| دریافت درخواست / پیام | ابزار کلاینت در حال اجراست یا پاسخ در چت آمده |
| پیش‌نمایش آماده | طرح هنوز اجرا نشده؛ Apply یا Cancel در راینو |
| اعمال شد | هندسهٔ بومی ثبت شده؛ کلاینت می‌تواند نتیجه را بخواند |
| تماس تازه دریافت نشده / نشست بسته شد | زمان آخرین پیام یا بسته‌شدن پل نشان داده می‌شود؛ اتصال دائمی فرض نمی‌شود |

## Generate، Analyze و Assist

- Generate: ساخت هندسهٔ جدید، انتخاب نما و لایه؛ پیش‌نمایش سپس Apply.
- Analyze: انتخاب اشیا یا Recent output؛ گزارش ابعاد، سلامت هندسه و لایه‌ها. Run local audit به API نیاز ندارد و هندسه را تغییر نمی‌دهد. تحلیل مهندسی/مقرراتی ارائه نمی‌شود.
- Assist: ویرایش انتخاب یا خروجی اخیر. Move فاصله و محور دارد؛ Scale ضریب است (۲ دو برابر و ۰٫۵ نصف)؛ Extrude ارتفاع منحنی مناسب را می‌گیرد. Ctrl+Z اجرای مرحله را برمی‌گرداند.

## ChatGPT وب

اتصال محلی از راه MCP شدنی است، ولی بازکردن ChatGPT یا ارسال JSON تنظیمات در چت، اتصال را برقرار نمی‌کند. محصولات پشتیبانی‌شده می‌توانند با مسیر remote یا **Secure MCP Tunnel** به MCP خصوصی وصل شوند؛ ثبت اتصال در حساب و قابلیت‌های همان حساب نیز لازم است. آرشتک در این نسخه تونل، OAuth یا ارسال خودکار به تب وب را راه‌اندازی نمی‌کند. [مستندات رسمی مسیر MCP و Tunnel](https://developers.openai.com/api/docs/guides/tools-connectors-mcp)

برای کارکرد مستقیم چت داخل خود پلاگین، مسیر API شخصی فعلاً راه پیاده‌شده است. اشتراک یک اپلیکیشن به‌خودی‌خود API Key آن سرویس نیست.

## بررسی API

Save this profile ذخیره/فعال‌شدن پروفایل را نشان می‌دهد. Remember ذخیرهٔ رمزگذاری‌شده پس از خروج از راینو را تعیین می‌کند. Test network بدون کلید فقط دسترسی شبکه را می‌سنجد؛ HTTP 401 در این آزمون به معنی پاسخ‌دادن میزبان است. **Connect and discover models** اعتبار دسترسی و فهرست مدل را بررسی می‌کند. پس از انتخاب مدل، یک درخواست کوچک و پیش‌نمایش را امتحان کنید. کیفیت و هزینهٔ پاسخ به سرویس/مدل و حساب شما بستگی دارد؛ نتیجهٔ آزمون بدون کلید، تأیید کارکرد حساب نیست.
