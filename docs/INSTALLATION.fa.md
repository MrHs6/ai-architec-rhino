# نصب AI Archi-Tec در Rhino 8

[صفحهٔ اصلی](../README.md) · [اتصال API/MCP](CONNECTIONS.fa.md) · [دانلود نسخه‌ها](https://github.com/MrHs6/ai-architec-rhino/releases)

## پیش‌نیاز

- Windows x64 و نصب معتبر **Rhino 8.31 یا جدیدتر از شاخهٔ Rhino 8** با runtime **.NET 8**.
- اینترنت و حساب سرویس برای استفاده از مدل آنلاین؛ یا کلاینت دسکتاپ سازگار برای اتصال MCP.
- هر کاربر کلید API خودش را وارد می‌کند. Visual Studio، Node و SDK برای نصب فایل آماده لازم نیستند.

## روش پیشنهادی: نصب‌کنندهٔ ویندوز

1. [نسخهٔ بتا](https://github.com/MrHs6/ai-architec-rhino/releases/tag/rhino-v0.6.0-beta.9) را باز کنید و از **Assets** فایل `ai-architec-rhino-0.6.0-beta.9-windows-installer.zip` را بگیرید. گزینهٔ **Source code** نصب‌کننده نیست.
2. ZIP را با **Extract All** استخراج کنید؛ `install.cmd` و فایل `.yak` باید کنار هم باشند.
3. سندتان را ذخیره کنید و تمام پنجره‌های راینو را ببندید؛ سپس `install.cmd` را اجرا کنید. نصب برای همان حساب ویندوز با Yak همراه راینو انجام می‌شود.
4. پس از پیام موفقیت، راینو را دوباره باز کنید.
5. در صفحهٔ فرمان بنویسید `archtec` و Enter بزنید.
6. برای چت در راینو، در API profiles سرویس، کلید و مدل را انتخاب کنید؛ یا برای گفتگو در Codex/Claude Desktop از MCP connection و دکمهٔ Connect استفاده کنید. [راهنمای اتصال](CONNECTIONS.fa.md) · [آموزش تصویری انگلیسی](INSTALLATION.en.md)

نسخهٔ نصب‌شده تنظیمات دیگر کاربران یا API اشتراکی ندارد. پیام‌های Windows و سیاست‌های سازمانی دستگاهتان را طبق روال خود بررسی کنید؛ نصب‌کننده سیاست اجرای PowerShell را عوض نمی‌کند و سطح دسترسی Administrator درخواست نمی‌کند.

## نصب با CMD

پس از استخراج ZIP، CMD را در همان پوشه باز کنید:

```cmd
install.cmd
```

یا مسیر یک بستهٔ محلی را بدهید:

```cmd
install.cmd "D:\Downloads\ai-architec-rhino-0.6.0-beta.9-rh8_31-win.yak"
```

اگر راینو در مسیر دیگری نصب است:

```cmd
set "ARCHITEC_RHINO_SYSTEM=D:\Applications\Rhino 8\System"
install.cmd
```

فرمان `install.cmd /check` فقط وجود Yak و بستهٔ کنار نصب‌کننده را بررسی می‌کند؛ نصب یا آزمون اجرای پلاگین انجام نمی‌دهد. CMD مستقیماً Yak را اجرا می‌کند و به مجازبودن اسکریپت‌های PowerShell وابسته نیست.

## نصب مستقیم فایل Yak

فایل `.yak` نسخه را دانلود و روی پنجرهٔ Rhino بکشید، یا این فرمان را اجرا کنید:

```cmd
"%ProgramFiles%\Rhino 8\System\Yak.exe" install "D:\Downloads\ai-architec-rhino-0.6.0-beta.9-rh8_31-win.yak"
```

مسیر را مطابق دستگاه خود اصلاح کنید. سپس راینو را مجدداً اجرا کنید. نصب از جست‌وجوی عمومی **PackageManager** فقط پس از انتشار بسته در کاتالوگ مربوط در دسترس خواهد بود؛ فعلاً فایل این مخزن را نصب کنید.

## PowerShell و بررسی checksum

اگر اجرای اسکریپت طبق سیاست دستگاه مجاز است:

```powershell
.\install.ps1 -CheckOnly
.\install.ps1
```

PowerShell نسخهٔ راینو، هویت بسته و SHA256 همراه ZIP را بررسی می‌کند. فایل مستقل `SHA256SUMS.txt` نیز در Assets همان نسخه منتشر می‌شود. برای مشاهدهٔ hash دانلود:

```powershell
Get-FileHash .\ai-architec-rhino-0.6.0-beta.9-rh8_31-win.yak -Algorithm SHA256
```

برای نصب خودکار از URL مستقیم، `-PackageUrl` و `-Sha256` واقعی همان نسخه را به `install.ps1` بدهید. برای نصب بدون تغییر سند/بسته از `-WhatIf` استفاده کنید. جزئیات در [راهنمای توزیع](../rhino-plugin/docs/DISTRIBUTION.md) آمده است.

## بازکردن پنل و تنظیمات

| محل | عملکرد |
|---|---|
| فرمان `archtec` | بازکردن پنل |
| فرمان `AIArchitect` | نام جایگزین برای بازکردن پنل |
| فرمان `AIArchitectFloat` | نمایش پنل شناور |
| Tools → Options → AI Archi-Tec | تنظیمات شخصی اتصال |
| Tools → Options → Plug-ins | مدیریت نصب و بارگذاری پلاگین |

پس از واردکردن تنظیمات در Options، در Studio → API profiles فهرست مدل‌ها را دریافت و مدل را انتخاب کنید. تغییر تنظیمات، به‌تنهایی درخواست پولی به سرویس ارسال نمی‌کند.

## اولین مدل

بدون کلید، حالت **Offline examples** را انتخاب و این نمونهٔ عددی را ارسال کنید:

```text
Create a 15 x 20 meter building with 5 floors and 3.2 meter floor heights and a glazed facade.
```

**Generate → بررسی پیش‌نمایش → Apply to Rhino**. برای برگشت، در خود راینو **Ctrl+Z** بزنید. برای فرمان‌های آزاد و ورودی تصویر به مدل آنلاین سازگار نیاز دارید؛ پارسر آفلاین عمومی نیست.

## به‌روزرسانی و حذف

برای به‌روزرسانی، بستهٔ نسخهٔ جدید را با همان روش نصب و راینو را مجدداً اجرا کنید. کلید اختیاری ذخیره‌شده به همان حساب ویندوز تعلق دارد و در بستهٔ آپدیت جابه‌جا نمی‌شود.

برای حذف، از PackageManager استفاده کنید یا این دستور را اجرا کنید:

```cmd
"%ProgramFiles%\Rhino 8\System\Yak.exe" uninstall ai-architec-rhino
```

سپس راینو را دوباره باز کنید. حذف بسته به‌تنهایی فایل تنظیمات شخصی `%LOCALAPPDATA%\AIArchiTec\Rhino8\connection.json` را پاک نمی‌کند.

## رفع خطا

### پنل خاکستری با کادرهای خالی یا بازگشت ظاهر قدیمی

پیش از نصب، سندتان را ذخیره و **تمام پنجره‌های راینو را ببندید**. ثبت مسیر درحالی‌که نمونهٔ قدیمی باز است کافی نیست، چون راینو می‌تواند هنگام خروج مسیر ذخیره‌شدهٔ قبلی را دوباره بنویسد. نصب‌کننده و ابزار ترمیم اکنون این وضعیت را متوقف و پیام روشن نمایش می‌دهند.

اگر قبلاً نمونهٔ آزمایشی را با کشیدن فایل `.rhp` داخل راینو نصب کرده‌اید، ممکن است ثبت دستی نسخهٔ `0.1` بر بستهٔ جدید Yak مقدم باشد. نصب ZIP نسخهٔ `0.6.0-beta.9` ابتدا Yak را نصب می‌کند، سپس فقط ثبت همین پلاگین را در حساب ویندوز اصلاح می‌کند و فرمان `archtec` را اضافه می‌کند. از ثبت قبلی در `%LOCALAPPDATA%\AIArchiTec\InstallationBackups` فایل `.reg` پشتیبان گرفته می‌شود. پس از نصب، سند را ذخیره و راینو را دوباره اجرا کنید؛ اسمبلی بارگذاری‌شده در همان اجرای قبلی قابل تعویض نیست.

در **About** نسخه و مسیر فایل بارگذاری‌شده را بررسی کنید. مسیر نصب Yak معمولاً چنین است:

```text
%APPDATA%\McNeel\Rhinoceros\packages\8.0\ai-architec-rhino\0.6.0-beta.9\AIArchiTec.rhp
```

برای بررسی بدون تغییر، از پوشهٔ ZIP استخراج‌شده اجرا کنید:

```powershell
.\repair-registration.ps1 -PackagePath .\ai-architec-rhino-0.6.0-beta.9-rh8_31-win.yak -CheckOnly
```

اگر اجرای PowerShell طبق سیاست دستگاه محدود است، `install.cmd` از ابزار بومی `repair-registration.cmd` استفاده می‌کند و تغییر سیاست لازم نیست. اگر ترمیم ثبت شکست بخورد، نصب‌کننده نتیجه را خطا اعلام می‌کند. نصب مستقیم Yak به‌تنهایی ثبت دستی قدیمی را ترمیم نمی‌کند. فایل‌ها و تنظیمات شخصی قبلی حذف نمی‌شوند.

| مشکل | بررسی |
|---|---|
| `Unknown command: archtec` | نصب موفق و restart را بررسی کنید؛ در Plug-ins وجود پلاگین و فعال‌بودن آن را ببینید. نسخهٔ راینو و runtime باید مطابق پیش‌نیاز باشند. |
| `Rhino 8 was not found` | مسیر نصب سفارشی را با `ARCHITEC_RHINO_SYSTEM` در CMD یا `-RhinoSystemDir` در PowerShell بدهید. |
| اجرای PowerShell محدود است | از `install.cmd` یا فرمان مستقیم Yak استفاده کنید؛ تغییر سیاست لازم نیست. |
| فهرست مدل یا پاسخ API خطا دارد | نشانی، اعتبار کلید، اعتبار حساب و پشتیبانی مدل از `json_schema` را بررسی کنید. |
| MCP پورت را باز نمی‌کند | فقط یک سرور روی پورت 5188 همان کامپیوتر اجرا شود؛ از بخش پیشرفته پورت آزاد انتخاب و تنظیم کلاینت را هماهنگ کنید. |
| مدل بعد از Generate دیده نمی‌شود | Generate پیش‌نمایش است؛ پس از بررسی Apply بزنید. در صورت نیاز از Zoom Extents راینو استفاده کنید. |
| طرح قدیمی قابل اجرا نیست | سند، واحد یا هدف ممکن است تغییر کرده باشد؛ طرح تازه تولید کنید. |
