# AI Archi-Tec برای Rhino 8

[صفحهٔ اصلی انگلیسی و معرفی گرافیکی](../README.md) · [دانلود نسخهٔ 0.4.2-beta.1](https://github.com/MrHs6/ai-architec-rhino/releases/tag/rhino-v0.4.2-beta.1)

آرشتک یک دستیار مدل‌سازی مفهومی داخل راینو است. با فرمان **archtec** پنل را باز کنید؛ از API شخصی یا کلاینت دسکتاپ MCP استفاده کنید، پیش‌نمایش را ببینید و با **Apply to Rhino** هندسهٔ قابل ویرایش بسازید. رابط و دیاگرام‌های محصول انگلیسی‌اند؛ پرامپت فارسی پشتیبانی می‌شود.

![معرفی محصول؛ برچسب‌های انگلیسی](assets/product-cover.png)

## نصب و اتصال

1. نصب‌کنندهٔ Windows ZIP را از Releases دانلود و همهٔ فایل‌ها را استخراج کنید.
2. سندتان را ذخیره، تمام پنجره‌های راینو را ببندید و install.cmd را اجرا کنید.
3. راینو را باز و فرمان archtec را وارد کنید.
4. برای چت داخل راینو، API profiles را با سرویس، کلید و مدل خودتان تنظیم کنید.
5. برای MCP، کلاینت Codex/Claude Desktop را انتخاب و Connect بزنید؛ گفتگو در کلاینت و پیش‌نمایش و Apply در راینو انجام می‌شود. اولین نصب/ارتقا ممکن است به یک refresh کلاینت نیاز داشته باشد؛ خاموش‌و‌روشن‌کردن بعدی MCP خودکار بازیابی می‌شود.

## سه فضای کاری

- **Generate:** ایجاد هندسهٔ جدید، با پیش‌نمایش و Apply.
- **Analyze:** گزارش خواندنی از ابعاد، سلامت هندسه و لایه‌ها؛ تحلیل محلی بدون API هم کار می‌کند.
- **Assist:** جابه‌جایی، تغییر مقیاس و extrusion روی انتخاب یا خروجی اخیر با پیش‌نمایش تازه.
