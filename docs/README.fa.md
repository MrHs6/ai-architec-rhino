**نسخهٔ آزمایشی 0.6.0-beta.9:** ساخت و ویرایش گراف بومی گرسهاپر با همان MCP یا گفتگوی API، اتصال دقیق‌تر سرویس‌ها، حفظ شناسهٔ اشیا در ویرایش بعدی و پنل خواناتر با اسکرول مشترک. [راهنمای گرسهاپر و محدودیت‌ها](GRASSHOPPER.fa.md).

آرشتک یک دستیار مدل‌سازی مفهومی داخل راینو است. با فرمان **archtec** پنل را باز کنید؛ از API شخصی یا کلاینت دسکتاپ MCP استفاده کنید، در مسیر API پیش‌نمایش و **Apply to Rhino**، و در MCP اجرای مجازشده و بررسی نتیجه در همان کلاینت انجام می‌شود. رابط و دیاگرام‌های محصول انگلیسی‌اند؛ پرامپت فارسی پشتیبانی می‌شود.

## نمونهٔ ساخته‌شده با AI Archi-Tec: برج آزادی

![نمای رندرشدهٔ معمولی مدل نهایی برج در راینو](../rhino-plugin/docs/azadi-tower-render.png)

این مدل با هدایت کدکس و اجرای ابزارهای بومی MCP همین پلاگین در راینو ساخته شده است. ۳۳۹ قطعهٔ بسته و معتبر دارد؛ چهار پایه، مسیرهای عبور باز، طاق منحنی، شبکهٔ سنگی و جزئیات تاج در فایل قابل‌ویرایش قرار دارند. تصویر، نمای واقعی مدل نهایی در حالت Rendered راینو است. دقت آن در حد بازسازی تصویری با جزئیات ابعادی فرض‌شده است.

[دانلود مدل قابل‌ویرایش برج](https://github.com/MrHs6/ai-architec-rhino/releases/download/rhino-v0.6.0-beta.9/Azadi-Tower-Reference-Rebuild.3dm) · [فرایند ساخت و کنترل هندسه](AZADI-MCP-DEMO.en.md)

## نصب و اتصال

1. نصب‌کنندهٔ Windows ZIP را از Releases دانلود و همهٔ فایل‌ها را استخراج کنید.
2. سندتان را ذخیره، تمام پنجره‌های راینو را ببندید و install.cmd را اجرا کنید.
3. راینو را باز و فرمان archtec را وارد کنید.
4. برای چت داخل راینو، API profiles را با سرویس، کلید و مدل خودتان تنظیم کنید.
5. برای MCP، کلاینت Codex/Claude Desktop را انتخاب و Connect بزنید؛ تمام گفتگو، اجرای ابزار، بررسی و اصلاح در کلاینت انجام می‌شود؛ Apply محلی لازم نیست. اولین نصب/ارتقا ممکن است به یک refresh کلاینت نیاز داشته باشد؛ خاموش‌و‌روشن‌کردن بعدی MCP خودکار بازیابی می‌شود.

## سه فضای کاری مسیر API

- **Generate:** ایجاد هندسهٔ جدید، با پیش‌نمایش و Apply.
- **Analyze:** گزارش خواندنی از ابعاد، سلامت هندسه و لایه‌ها؛ تحلیل محلی بدون API هم کار می‌کند.
- **Assist:** جابه‌جایی، تغییر مقیاس و extrusion روی انتخاب یا خروجی اخیر با پیش‌نمایش تازه.

نسخهٔ فعلی برای Windows x64، Rhino 8.31+ و .NET 8 است. ۱۹۶ تست خودکار، ۳۹ بررسی چیدمان و ۹ مرحلهٔ تست زندهٔ OpenRouter موفق بوده‌اند. تست زنده با مدل انتخاب‌شدهٔ openai/gpt-4.1-mini شامل پاسخ فارسی، باکس بستهٔ ۲ × ۴ × ۳ متر و جابه‌جایی همان شیء با حفظ شناسه بود. نمونهٔ برج آزادی ۳۳۹ Brep معتبر و بسته دارد و بازسازی تصویری با ابعاد فرض‌شده است. تست زندهٔ سایر حساب‌ها، کیفیت تصویر، تولید گراف گرسهاپر با سرویس پولی و دستگاه دوم هنوز تأیید نشده است. این نسخه BIM، نقشهٔ اجرایی، رندر فوتورئال یا تحلیل مهندسی ارائه نمی‌کند. توزیع Food4Rhino با کاتالوگ عمومی Yak متفاوت است.
