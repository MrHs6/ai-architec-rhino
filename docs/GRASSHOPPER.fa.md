# استفاده از گرسهاپر با AI Archi-Tec

نسخهٔ آزمایشی **0.6.0-beta.10** شامل ساخت و ویرایش گراف بومی گرسهاپر است. [نصب‌کنندهٔ نسخهٔ جدید](https://github.com/MrHs6/ai-architec-rhino/releases/tag/rhino-v0.6.0-beta.10) هم راینو و هم گرسهاپر را پشتیبانی می‌کند. سیستم مورد نیاز: ویندوز ۶۴ بیتی، راینو ۸ دارای لایسنس از نسخهٔ 8.31 به بالا، گرسهاپر و محیط ‎.NET 8‎ راینو.

## پنل را کجا باز کنم؟

فرمان **`archtec` را در خط فرمان راینو** بنویسید. این فرمان داخل جست‌وجوی کامپوننت‌های گرسهاپر اجرا نمی‌شود. پنل شناور پلاگین را کنار بوم گرسهاپر نگه دارید. در این نسخه فایل `.gha` یا کامپوننت و پنل مستقل داخل گرسهاپر نصب نمی‌شود؛ همان پلاگین راینو، گرسهاپر را کنترل می‌کند.

## مسیر MCP

۱. نسخهٔ جدید را نصب کنید، راینو را دوباره باز کنید و `archtec` را اجرا کنید.

۲. در MCP connection کلاینت را انتخاب و Connect کنید. همان اتصال راینو برای گرسهاپر هم کافی است؛ سرور دوم لازم نیست. بعد از ارتقا ممکن است یک بار تازه‌سازی فهرست ابزارهای کلاینت لازم باشد.

۳. در کدکس یا کلاینت سازگار خود بنویسید: «در Grasshopper یک تعریف پارامتریک قابل‌ویرایش بساز، با اسلایدرهای عرض ۲، عمق ۴ و ارتفاع ۳ در واحد سند؛ فعلاً Bake نکن. خروجی و خطاهای کامپوننت‌ها را بررسی کن.»

۴. گفتگو، برنامه‌ریزی، اجازهٔ اجرای ابزار و ادامهٔ ویرایش در همان کلاینت انجام می‌شود. کلیک Apply در راینو لازم نیست. کلاینت باید ابزارهای `ai-architec-rhino` را در اختیار داشته باشد؛ بازکردن سایت ChatGPT به‌تنهایی اتصال محلی ایجاد نمی‌کند.

۵. برای اصلاح بگویید «همان تعریف را تغییر بده» تا از شناسهٔ تعریف قبلی استفاده شود. فقط وقتی خروجی مستقل راینو می‌خواهید، Bake را درخواست کنید. فایل `.gh` را در خود گرسهاپر ذخیره کنید.

خاموش‌کردن اتصال، درخواست‌های جدید را متوقف می‌کند و روشن‌کردن دوباره، ارتباط پل ثبت‌شده را برقرار می‌کند. Stop کلاینت برای لغو درخواست جاری است و عملیات قبلاً ثبت‌شده را Undo نمی‌کند. لغو محاسبه به پاسخ‌دادن کامپوننت بومی وابسته است.

## مسیر API

۱. در پنل، مسیر **Chat here · API / offline tools** را انتخاب کنید.

۲. مقصد **Grasshopper · parametric definition** را انتخاب کنید.

۳. حساب API شخصی یا آدرس محلی سازگار را متصل و مدل موردنظر را انتخاب کنید. اعتبار یا هزینهٔ مدل همراه پلاگین نیست و به سرویس شما مربوط است.

۴. درخواست را داخل پنل بنویسید. طرح ساختاریافتهٔ تعریف نمایش داده می‌شود؛ این مرحله پیش‌نمایش پلان گراف است و هنوز محاسبه نشده است. با Apply، کامپوننت‌ها ساخته و حل می‌شوند.

۵. ادامهٔ گفتگو را در همان پنل انجام دهید. تاریخچهٔ API برای راینو و گرسهاپر جداست. مثال‌های آفلاین راینو، تعریف گرسهاپر تولید نمی‌کنند.

## چه چیزی قابل استفاده است؟

کامپوننت‌های بومی پشتیبانی‌شده، اسلایدر عددی، ورودی‌های دارای شاخهٔ داده، اتصال سیم‌ها، بررسی خروجی و خطا و Bake صریح هندسه. کتابخانه‌های Curve، Surface، Vector، Math، Transform، Triangulation و Field بررسی می‌شوند. این نسخه همهٔ افزونه‌های جانبی یا اسکریپت و کلاستر را اجرا نمی‌کند.

هر تعریف حداکثر ۲۰۰ نود و ۵۰۰ اتصال دارد. واحدها، واحد سند راینو هستند. ویرایش خودکار فعلاً به تعریف‌هایی محدود است که همین پل در همین نشست و سند ساخته است. فایل‌های دلخواه یا دوباره بازشده قابل بررسی‌اند، ولی برای جایگزینی خودکار پذیرفته نمی‌شوند. بعد از ویرایش دستی یا Undo، وضعیت فعلی گراف باید دوباره خوانده شود؛ آخرین recipe الزاماً وضعیت فعلی نیست.

Undo گراف در گرسهاپر و Undo هندسهٔ Bake‌شده در راینو مستقل‌اند. هندسهٔ Bake‌شده با تغییر بعدی اسلایدرها خودکار به‌روز نمی‌شود. قبل از گسترش تعریف، خروجی‌ها و هشدارها را بررسی کنید و فایل‌ها را ذخیره کنید.
