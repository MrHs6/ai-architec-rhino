# اتصال API و MCP

[صفحهٔ اصلی](../README.md) · [نصب](INSTALLATION.fa.md)

## API شخصی

1. با `archtec` پنل را باز و **API profiles** را انتخاب کنید.
2. منبع را روی **OpenRouter**، **OpenAI**، **xAI / Grok**، **Google Gemini**، **Anthropic / Claude** یا **OpenAI-compatible / local** بگذارید.
3. نشانی پایه و کلید همان سرویس را وارد کنید. نشانی پیش‌فرض OpenRouter: `https://openrouter.ai/api/v1/` و OpenAI: `https://api.openai.com/v1/`.
4. برای نگه‌داری کلید پس از بستن راینو، **Remember securely after restarting Rhino** را روشن کنید. **Save this profile** پروفایل را ذخیره و فعال می‌کند، حتی اگر شبکه در دسترس نباشد.
5. **Test network without key** دسترسی به میزبان را بدون ارسال کلید بررسی می‌کند. سپس **Connect and discover models** را بزنید؛ پس از دریافت فهرست، مدل را انتخاب و پروفایل را ذخیره کنید.
6. پرامپت را ارسال، پیش‌نمایش را بررسی و سپس Apply کنید. [آموزش ادامهٔ ویرایش همان مدل](CONVERSATIONAL-WORKFLOW.fa.md)

در OpenRouter فهرست براساس tools و structured outputs فیلتر می‌شود. Grok، Gemini و Claude اتصال مستقیم و قالب درخواست جدا دارند. هر سرویس کلید، نشانی و مدل مستقل دارد؛ تغییر سرویس، پیش‌نویس پروفایل قبلی را نگه می‌دارد. Save this profile تنظیمات همان سرویس را ذخیره می‌کند. [جزئیات پروتکل‌ها و منابع رسمی](PROVIDERS.md)

برای API سازگار، `/models`، `/chat/completions` و `response_format: json_schema` لازم‌اند. اتصال HTTPS برای سرور بیرونی الزامی است؛ HTTP فقط برای localhost پذیرفته می‌شود. برای مدل محلی، نشانی سرویس سازگار خودتان را بدهید؛ نصب یا دانلود مدل محلی توسط این پلاگین انجام نمی‌شود.

**Remember key securely** کلید را با DPAPI برای همان حساب ویندوز ذخیره می‌کند. بدون آن، کلید فقط در حافظه می‌ماند. پس از اجرای دوباره، Settings را باز و فهرست مدل‌ها را بارگیری کنید. کلید در GitHub یا برای کاربران دیگر ذخیره نمی‌شود.

وضعیت ذخیره زیر گزینهٔ Remember نشان داده می‌شود و از وضعیت شبکه جداست. شکست Connect پروفایل ذخیره‌شده را حذف نمی‌کند. HTTP 401 در آزمون بدون کلید یعنی میزبان پاسخ داده است؛ برای اعتبارسنجی کلید باید Connect انجام شود. خطای WSAEACCES / 10013 یعنی ویندوز ارتباط خروجی فرایند راینو را مسدود کرده و هنوز کلید بررسی نشده است؛ قانون خروجی مختص Rhino را با مدیر سیستم بررسی کنید. پلاگین تنظیمات فایروال را تغییر نمی‌دهد.

تصویر در Gemini با قالب بومی ارسال می‌شود. OpenRouter، xAI و Anthropic قابلیت تصویر را از اطلاعات مدل دریافت می‌کنند. اگر قابلیت تأیید نشود، تصویر پذیرفته نمی‌شود. در OpenAI و سرویس عمومی سازگار، vision از فهرست تأیید نشده و غیرفعال است. حجم مرجع کمتر از ۴ مگابایت و قالب PNG/JPG/JPEG است. کیفیت تفسیر تصویر همچنان به آزمون زنده نیاز دارد.

## MCP روی همان کامپیوتر

1. راینو و پنل را باز نگه دارید.
2. صفحهٔ **MCP connection** را باز، پورت را انتخاب و **Start localhost MCP** را بزنید. بازکردن صفحه به‌تنهایی سرور را روشن نمی‌کند.
3. سرور پیش‌فرض روی `http://127.0.0.1:5188/mcp` روشن می‌شود.
4. کلاینت را انتخاب کنید و **Copy Claude Desktop JSON** یا **Copy Codex TOML** را بزنید. خروجی را در تنظیمات برنامه ثبت کنید؛ ارسال آن در متن چت اتصال ایجاد نمی‌کند. [راهنمای کامل انگلیسی](MCP-QUICKSTART.en.md)
5. کلاینت را طبق روش خودش مجدداً بارگذاری کنید. ابتدا `get_context` و سپس `propose_plan` را اجرا کند.
6. طرح را در راینو بررسی و با **Apply to Rhino** اجرا کنید. کلاینت وضعیت را با `get_plan_status` می‌خواند.

شکل تنظیمات stdio به‌صورت زیر است؛ این مقادیر **نمونه‌اند** و باید از دکمهٔ خود پلاگین کپی شوند:

```json
{
  "mcpServers": {
    "ai-architec-rhino": {
      "command": "C:\\path\\to\\installed\\AIArchiTec.McpBridge.exe",
      "env": {
        "ARCHITEC_MCP_PORT": "5188"
      }
    }
  }
}
```

کلاینت دارای پشتیبانی Streamable HTTP می‌تواند مستقیم به endpoint وصل شود و هدر `Authorization: Bearer <local-token>` بفرستد. نسخه‌های پروتکل پشتیبانی‌شده: `2025-11-25`، `2025-06-18` و `2025-03-26`. GET stream ارائه نمی‌شود و پاسخ 405 می‌دهد؛ درخواست‌های JSON-RPC از POST استفاده می‌کنند.

| ابزار | کاربرد |
|---|---|
| `get_context` | شناسه و واحد سند، لایه‌ها و زمینهٔ محدود اشیای انتخابی/اخیر |
| `post_message` | نمایش پاسخ یا تحلیل کلاینت در گفت‌وگوی پنل، بدون تغییر هندسه |
| `propose_plan` | پیشنهاد طرح معتبر برای همان `document_id`؛ فقط پیش‌نمایش |
| `get_plan_status` | وضعیت درخواست و GUIDهای خروجی پس از اجرا |

توکن با هر شروع سرور عوض می‌شود؛ پل جدید آن را از کشف نشست رمزگذاری‌شده می‌خواند. پس از Stop/Start، اتصال کلاینت را Reload کنید. اگر مسیر bridge در ارتقای نسخه عوض شد، تنظیمات نسخهٔ تازه را کپی کنید. بستن پنل، سرور آن را متوقف می‌کند. دو رایانه می‌توانند همین پورت پیش‌فرض را داشته باشند؛ روی یک رایانه فقط یک سرور از همان پورت استفاده کند.

## سرویس ابری و ChatGPT

`127.0.0.1` به کامپیوتری اشاره می‌کند که کلاینت روی آن اجراست. یک وب‌سرویس ابری نمی‌تواند مستقیم به localhost ویندوز شما وصل شود. اتصال ابری به مسیر remote یا Secure MCP Tunnel و تنظیمات حساب پشتیبانی‌شده نیاز دارد؛ در این نسخه از کلاینت محلی استفاده کنید. این نسخه تونل عمومی، OAuth ابری و راه‌اندازی خودکار connector برای حساب ChatGPT ندارد. دکمهٔ بازکردن ChatGPT فقط سایت را باز می‌کند و پرامپت ارسال نمی‌کند.

پل و پروتکل محلی مستقیماً آزموده شده‌اند؛ اتصال با حساب واقعی تمام کلاینت‌های دسکتاپ یا اشتراک‌های ChatGPT/Claude هنوز تأیید نشده است.

## دادهٔ ارسال‌شده

در درخواست AI، متن کاربر، مکالمهٔ اخیر، اطلاعات واحد و لایه و مشخصات محدود اشیای انتخابی/اخیر ارسال می‌شوند. فایل کامل 3DM و عکس viewport خودکار ارسال نمی‌شوند. تصویر مرجع فقط با ضمیمه‌کردن و ارسال درخواست شما منتقل می‌شود. [توضیح داده‌ها و نگهداری کلید](../rhino-plugin/PRIVACY.md)
