# اتصال API و MCP

[صفحهٔ اصلی](../README.md) · [نصب](INSTALLATION.fa.md)

## API شخصی

1. با `archtec` پنل را باز و **API profiles** را انتخاب کنید.
2. منبع را روی **OpenRouter**، **OpenAI**، **xAI / Grok**، **Google Gemini**، **Anthropic / Claude** یا **OpenAI-compatible / local** بگذارید.
3. نشانی پایه و کلید همان سرویس را وارد کنید. نشانی پیش‌فرض OpenRouter: `https://openrouter.ai/api/v1/` و OpenAI: `https://api.openai.com/v1/`.
4. برای نگه‌داری کلید پس از بستن راینو، **Remember securely after restarting Rhino** را روشن کنید. **Save this profile** پروفایل را ذخیره و انتخاب می‌کند، حتی اگر شبکه در دسترس نباشد؛ ذخیره‌شدن به معنی اتصال موفق API نیست.
5. **Test network without key** دسترسی به میزبان را بدون ارسال کلید بررسی می‌کند. سپس **Connect and discover models** را بزنید؛ پس از دریافت فهرست، مدل را انتخاب و پروفایل را ذخیره کنید.
6. پرامپت را ارسال، پیش‌نمایش را بررسی و سپس Apply کنید. [آموزش ادامهٔ ویرایش همان مدل](CONVERSATIONAL-WORKFLOW.fa.md)

در OpenRouter ابتدا کلید با مسیر رسمی `/key` اعتبارسنجی و سپس فهرست عمومی `/models` دریافت می‌شود؛ دریافت فهرست عمومی به‌تنهایی اعتبار کلید را ثابت نمی‌کند. کلید مدیریت یا provisioning برای گفتگو پذیرفته نمی‌شود. فهرست مدل‌ها براساس قابلیت خروجی ساختاریافتهٔ JSON schema و متن فیلتر می‌شود؛ قابلیت tool calling لازم نیست. موفقیت اتصال و دریافت فهرست، موجودی حساب یا سازگاری همهٔ endpointها با درخواست نهایی را تضمین نمی‌کند. مدل جایگزین بدون انتخاب شما استفاده نمی‌شود.

Grok، Gemini و Claude اتصال مستقیم و قالب درخواست جدا دارند. هر سرویس کلید، نشانی و مدل مستقل دارد؛ تغییر سرویس، پیش‌نویس پروفایل قبلی را نگه می‌دارد. کلید OpenRouter را در پروفایل همان سرویس وارد کنید؛ استفاده از مدل Claude در OpenRouter، کلید را به کلید مستقیم Anthropic تبدیل نمی‌کند. [جزئیات پروتکل‌ها و منابع رسمی](PROVIDERS.md)

برای API سازگار، `/models`، `/chat/completions` و `response_format: json_schema` لازم‌اند. اتصال HTTPS برای سرور بیرونی الزامی است؛ HTTP فقط برای localhost پذیرفته می‌شود. برای مدل محلی، نشانی سرویس سازگار خودتان را بدهید؛ نصب یا دانلود مدل محلی توسط این پلاگین انجام نمی‌شود.

**Remember key securely** کلید را با DPAPI برای همان حساب ویندوز ذخیره می‌کند. بدون آن، کلید فقط در حافظه می‌ماند. پس از اجرای دوباره، Settings را باز و فهرست مدل‌ها را بارگیری کنید. کلید در GitHub یا برای کاربران دیگر ذخیره نمی‌شود.

وضعیت ذخیره زیر گزینهٔ Remember نشان داده می‌شود و از وضعیت شبکه جداست. شکست Connect پروفایل ذخیره‌شده را حذف نمی‌کند. HTTP 401 در آزمون بدون کلید یعنی میزبان پاسخ داده است؛ برای اعتبارسنجی کلید باید Connect انجام شود. خطای WSAEACCES / 10013 یعنی ویندوز ارتباط خروجی فرایند راینو را مسدود کرده و هنوز کلید بررسی نشده است؛ قانون خروجی مختص Rhino را با مدیر سیستم بررسی کنید. پلاگین تنظیمات فایروال را تغییر نمی‌دهد.

**عیب‌یابی خطاهای API:** پیام خطا دسته و کد HTTP را نشان می‌دهد و متن خام پاسخ، کلید، پرامپت یا شناسهٔ حساب را نمایش نمی‌دهد. 401 معمولاً به کلید/مجوز حساب، 402 به اعتبار API و 429 به محدودیت درخواست مربوط است. خطای بودجه می‌تواند از سقف کلید، workspace یا guardrail باشد. 403 به‌تنهایی به معنی نامعتبر بودن کلید نیست؛ ممکن است مجوز، سیاست سرویس یا درگاه شبکه درخواست را رد کرده باشد. پاسخ HTML یا پیام security policy را از خطای اعتبار کلید جدا بررسی کنید. اشتراک چت، اعتبار API را خودکار تأمین نمی‌کند.

**اگر تنظیمات شبکهٔ ویندوز هنگام بازبودن راینو تغییر کرده است:** محیط .NET 8 می‌تواند تنظیمات پروکسی را از زمان اولین استفادهٔ شبکه در همان فرایند نگه دارد؛ ساخت دوبارهٔ اتصال API این حافظهٔ مشترک را تازه نمی‌کند. فایل راینو را ذخیره، راینو را عادی ببندید و دوباره باز کنید؛ سپس Connect را بزنید. تنظیمات فعلی شبکه و اعتبارسنجی TLS را حفظ کنید. این یک مرحلهٔ عیب‌یابی براساس رفتار مستند .NET است و رفع محدودیت سرویس یا شبکه را تضمین نمی‌کند. پلاگین پروکسی/VPN را تغییر نمی‌دهد و درخواست مدل‌سازی ناموفق را خودکار تکرار نمی‌کند. [توضیح رسمی Microsoft](https://devblogs.microsoft.com/dotnet/dotnet-9-networking-improvements/)

پس از اتصال، ابتدا یک پیام کوتاه برای گفتگو و سپس یک درخواست کوچک مدل‌سازی بفرستید. پاسخ صرفاً متنی Apply ندارد؛ برای هندسه، پیش‌نمایش را بررسی و Apply کنید. برای ادامهٔ ویرایش همان مدل، شیء موجود یا خروجی اخیر را هدف بگیرید.

تصویر در Gemini با قالب بومی ارسال می‌شود. OpenRouter، xAI و Anthropic قابلیت تصویر را از اطلاعات مدل دریافت می‌کنند. اگر قابلیت تأیید نشود، تصویر پذیرفته نمی‌شود. در OpenAI و سرویس عمومی سازگار، vision از فهرست تأیید نشده و غیرفعال است. حجم مرجع کمتر از ۴ مگابایت و قالب PNG/JPG/JPEG است. کیفیت تفسیر تصویر همچنان به آزمون زنده نیاز دارد.

## MCP روی همان کامپیوتر

در **MCP connection** کلاینت را انتخاب و **Connect to Codex/Claude Desktop** را بزنید. ثبت تنظیمات خودکار است؛ در حالت MCP گفتگو در کلاینت انجام می‌شود و کادر چت راینو مخفی است. راینو گزارش و نتیجه را نشان می‌دهد؛ مجوز اجرا و اصلاح در همان کلاینت است و Apply محلی لازم نیست.

در اولین نصب یا ارتقا، کلاینت باز ممکن است به یک refresh نیاز داشته باشد. پس از آن خاموش و روشن‌شدن MCP راینو با همان کلاینت باز خودکار بازیابی می‌شود؛ کپی توکن و Reload مجدد لازم نیست. هنگام خاموشی درخواست اجرا نمی‌شود و خطای روشن برمی‌گردد. درخواست‌های مدل‌سازی مبهم خودکار تکرار نمی‌شوند.

[آموزش قدم‌به‌قدم فارسی](MCP-QUICKSTART.fa.md) · [English quick start](MCP-QUICKSTART.en.md)

ابزارها: **get_context** و **get_capabilities** زمینه و قرارداد ابزارها؛ **execute_plan** اجرای بومی با مجوز کلاینت و رسید UUID؛ **get_objects** بررسی هندسه؛ **set_view** و **get_viewport_image** بررسی تصویری. **propose_plan** اختیاری است و با **apply_plan/cancel_plan** در همان کلاینت مدیریت می‌شود. [گردش کار کامل MCP](MCP-QUICKSTART.fa.md). تنظیمات دستی و پورت در بخش **Manual setup and diagnostics** قرار دارند.

## سرویس ابری و ChatGPT

بازکردن وب‌سایت ChatGPT یک سرور STDIO محلی را ثبت نمی‌کند. مسیر ابری به connector یا Secure MCP Tunnel پشتیبانی‌شده و تنظیمات حساب نیاز دارد؛ این نسخه آن را خودکار راه‌اندازی نمی‌کند. مسیر Codex محلی و مسیر API شخصی در پنل جدا هستند. آزمون زندهٔ Codex روی رایانهٔ سازنده انجام شده؛ حساب واقعی Claude و رایانهٔ دوم هنوز آزموده نشده‌اند.

## دادهٔ ارسال‌شده

در درخواست AI، متن کاربر، مکالمهٔ اخیر، اطلاعات واحد و لایه و مشخصات محدود اشیای انتخابی/اخیر ارسال می‌شوند. فایل کامل 3DM و عکس viewport خودکار ارسال نمی‌شوند. تصویر مرجع فقط با ضمیمه‌کردن و ارسال درخواست شما منتقل می‌شود. [توضیح داده‌ها و نگهداری کلید](../rhino-plugin/PRIVACY.md)
