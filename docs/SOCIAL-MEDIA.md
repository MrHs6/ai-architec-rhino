## فارسی

نسخهٔ بتای **AI Archi-Tec for Rhino 8** منتشر شد.

با دستور `archtec`، دستیار مدل‌سازی را داخل راینو باز کنید؛ ایده را وارد کنید، پیش‌نمایش را ببینید و با Apply هندسهٔ قابل ویرایش را در همان سند بسازید.

اتصال با API شخصی، MCP محلی، مدل مفهومی چندطبقه، لایه‌بندی و Undo در راینو. نصب‌کنندهٔ ویندوز و راهنمای فارسی/انگلیسی در گیت‌هاب:

https://github.com/MrHs6/ai-architec-rhino

نیازمند Windows و Rhino 8.31+ با لایسنس معتبر. این نسخه برای آزمایش مدل‌سازی مفهومی است؛ حساب و هزینهٔ AI متعلق به سرویس انتخابی هر کاربر است. پشتیبانی از هر مدل یا بازسازی دقیق هر تصویر ادعا نمی‌شود.

## English

**AI Archi-Tec for Rhino 8 — public beta**

Type `archtec` inside Rhino, describe a concept, inspect the preview and Apply editable native geometry to your current document.

Bring your own API key or connect a compatible desktop client through local MCP. Includes multi-floor concept buildings, layers and native Undo. Windows installer, source and setup guides:

https://github.com/MrHs6/ai-architec-rhino

Requires Windows and licensed Rhino 8.31+. Concept-modeling beta; provider costs belong to each user's account. Live vision/provider acceptance and clean-start validation on another machine remain outstanding.
