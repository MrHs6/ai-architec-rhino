# بررسی روند کار پلاگین‌های مرجع و تصمیم‌های آرشتک

تاریخ بررسی: ۲۱ اکتبر ۲۰۲۶. این بررسی از صفحات انتشار و مستندات خود سازندگان انجام شده؛ نصب و اجرای این چهار محصول در این مرحله انجام نشده است. بعضی صفحات Food4Rhino درخواست تأیید انسانی داشتند؛ برای آن‌ها از سایت یا مخزن رسمی همان سازنده استفاده شد. توضیحات زیر ادعای سازندگان را از قابلیت پیاده‌شدهٔ آرشتک جدا می‌کند.

## روند پیاده‌شده در آرشتک 0.4

1. **انتخاب سرویس:** OpenAI، OpenRouter، Gemini، Anthropic، Grok یا آدرس سازگار محلی. آدرس پیش‌فرض هر سرویس مشخص است. کلیدهای شناخته‌شدهٔ یک سرویس به سرویس دیگری ارسال نمی‌شوند.
2. **Save یا Connect:** پروفایل انتخاب‌شده فعال می‌شود. فهرست مدل‌ها برای ذخیره‌شدن پروفایل الزامی نیست. گزینهٔ Remember تعیین می‌کند کلید با DPAPI در همان حساب ویندوز ذخیره شود یا فقط تا پایان اجرای راینو بماند.
3. **آزمون شبکه:** بدون ارسال کلید یا دادهٔ مدل، رسیدن به میزبان بررسی می‌شود. پاسخ HTTP 401 برای این آزمون یعنی میزبان پاسخ داده؛ اعتبار کلید هنوز بررسی نشده است. خطای سوکت 10013 جداگانه توضیح داده می‌شود.
4. **درخواست و پیش‌نمایش:** مدل فقط طرح ابزارهای مجاز را پیشنهاد می‌دهد. پیش‌نمایش سند را تغییر نمی‌دهد و Apply یک مرحلهٔ Undo بومی می‌سازد.
5. **گزارش نتیجه:** تعداد اجزای ساخته/ویرایش‌شده، ابعاد بازخوانی‌شده و اطلاعات طبقات در چت می‌آید. گزارش به زبان درخواست ساخته می‌شود و درخواست پولی اضافه‌ای ندارد.
6. **ادامهٔ طراحی:** Refine result همان خروجی را در Assist هدف می‌گیرد. یک فرمان روشن مثل جابه‌جایی، در چت Generate نیز به ادامهٔ ویرایش هدایت می‌شود. تغییر دستی یا Undo روی خروجی، اندازه‌گیری و پیام وضعیت را تازه می‌کند.
7. **سند دیگر:** سابقه، ورودی و GUIDهای اخیرِ سندها با هم مخلوط نمی‌شوند. این حافظه مربوط به نشست جاری است؛ سابقهٔ پروژه در فایل 3DM ذخیره نمی‌شود.

## مسیر انتشار عمومی

آماده‌سازی فایل Yak، نصب‌کنندهٔ CMD، checksum، راهنمای فارسی/انگلیسی و تصاویر واقعی در مخزن پروژه انجام می‌شود. انتشار روی Package Manager به احراز هویت حساب مالک با `Yak login` و سپس `Yak push` نیاز دارد. راهنمای رسمی توضیح می‌دهد نسخهٔ منتشرشده قابل بازنویسی نیست؛ نسخهٔ تازه باید شمارهٔ تازه داشته باشد. [راهنمای رسمی انتشار Yak](https://developer.rhino3d.com/en/guides/yak/pushing-a-package-to-the-server/)

Food4Rhino صفحهٔ معرفی و توزیع محصول را فراهم می‌کند و امکان ارتباط با بستهٔ Package Manager را دارد. متن صفحه باید با قابلیت‌های تست‌شده، پلتفرم، نسخه، هزینهٔ API و مجوز واقعی تطبیق داشته باشد. متن آمادهٔ صفحه در [پیش‌نویس انتشار](../rhino-plugin/docs/FOOD4RHINO.md) است. [توضیح رسمی McNeel دربارهٔ ارتباط Food4Rhino و Package Manager](https://www.rhino3d.com/en/e-news/0224f4r_dev/)

ورود به حساب ناشر و انتشار واقعی روی Food4Rhino/Yak جدا از ساخت بسته است؛ آماده‌بودن بسته به معنی منتشرشدن در آن سایت‌ها نیست.
