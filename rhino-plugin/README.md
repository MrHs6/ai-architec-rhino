# AI Archi-Tec for Rhino 8

**[صفحهٔ عمومی پروژه و دانلود نصب‌کننده](https://github.com/MrHs6/ai-architec-rhino)** · [راهنمای نصب](https://github.com/MrHs6/ai-architec-rhino/blob/main/docs/INSTALLATION.fa.md) · [English](https://github.com/MrHs6/ai-architec-rhino/blob/main/docs/README.en.md)

نسخه آزمایشی واقعی برای Rhino 8 روی Windows؛ طراحی و مالکیت محصول: **Hasan Sharif Askari**.

## نصب و اجرا

1. Rhino 8.31 یا جدیدتر با runtime دات‌نت ۸ و لایسنس معتبر لازم است. محیط آزمون: Rhino **8.31.26126.13431** و .NET **8.0.14**، ویندوز x64.
2. فایل `windows-installer.zip` را استخراج و **`install.cmd`** را اجرا کنید؛ یا فایل `.yak` را روی پنجره Rhino بکشید. نصب را تکمیل و Rhino را مجدداً اجرا کنید. برای نصب دستی، همه فایل‌های پوشه بسته را کنار هم نگه دارید و `AIArchiTec.rhp` را از `PlugInManager` بارگذاری کنید.
3. در خط فرمان راینو **`archtec`** را تایپ و Enter بزنید. فرمان **`AIArchitect`** هم پشتیبانی می‌شود. برای حالت شناور **`AIArchitectFloat`** را اجرا کنید. پنل قابلیت Dock دارد.
4. بخش **Tools > Options > AI Archi-Tec** تنظیمات شخصی اتصال را در اختیار شما می‌گذارد. بخش **Tools > Options > Plug-ins** برای مدیریت نصب و بارگذاری پلاگین است.

برای اجرای بسته آماده، نصب SDK، Visual Studio یا Node لازم نیست. نصب CMD به تغییر سیاست اجرای PowerShell نیاز ندارد. راهنمای نصب گروهی، CMD/PowerShell، GitHub، GitLab و به‌روزرسانی در [docs/DISTRIBUTION.md](docs/DISTRIBUTION.md) است.

## اتصال با API Key شخصی

در **Settings** سرویس را انتخاب کنید: **OpenRouter**، **OpenAI** یا **OpenAI-compatible / local**. نشانی پایه API و کلید شخصی را وارد کنید و **Load compatible models** را بزنید. مدل را انتخاب و **Save and close** را بزنید.

- برای OpenRouter فهرست زنده براساس پشتیبانی از structured outputs و tools فیلتر می‌شود.
- سرویس‌های سازگار باید `/models` و `/chat/completions` و `response_format: json_schema` را پشتیبانی کنند. فهرست عمومی OpenAI اطلاعات کامل قابلیت مدل‌ها را ندارد؛ مدل ناسازگار خطای صریح می‌دهد. پشتیبانی از تصویر در این منابع تأییدنشده است و در نسخه حاضر غیرفعال می‌ماند.
- شناسه مدل عیناً ارسال می‌شود و تعویض مدل مخفی وجود ندارد.
- کلید در حافظه است. با گزینه **Remember key securely**، کلید با Windows DPAPI برای همان حساب کاربری رمزگذاری می‌شود؛ کلید داخل سورس یا بسته نصب نیست.
- پس از اجرای مجدد، Settings را باز کنید و فهرست مدل‌ها را دوباره بارگیری کنید؛ کلید ذخیره‌شده، در صورت انتخاب گزینه ذخیره، بازیابی می‌شود.
- حالت **Offline examples** تنها پارسر محدود ساختمان مستطیلی، باکس و جابه‌جایی است؛ هوش مصنوعی آزاد نیست.

مثال بدون کلید:

```text
Create a box 10 x 15 x 12 meters on layer AI_Building.
Move the box 2 meters along X
```

**Generate** فقط طرح و پیش‌نمایش می‌سازد. **Apply to Rhino** عملیات را اجرا می‌کند. **Cancel** پیش‌نمایش را حذف می‌کند. **Ctrl+Z در راینو** اجرای یک بسته عملیات را برمی‌گرداند. در Analyze، زمینه مدل خوانده می‌شود؛ AI در این حالت اجازه پیشنهاد تغییر هندسه ندارد.

## اتصال MCP

دکمه **MCP · Connect localhost** سرور محلی را روشن می‌کند. آدرس پیش‌فرض `http://127.0.0.1:5188/mcp` است. **Copy desktop client configuration** تنظیمات پل stdio را برای کلاینت دسکتاپ مانند Claude Desktop کپی می‌کند. این تنظیمات شامل مسیر پل نصب‌شده و یک توکن محلی است؛ آن را عمومی منتشر نکنید.

در کلاینت دارای پشتیبانی Streamable HTTP می‌توان مستقیم از نشانی بالا و هدر `Authorization: Bearer <local-token>` استفاده کرد. پروتکل‌های 2025-11-25، 2025-06-18 و 2025-03-26 پشتیبانی می‌شوند. GET stream اختیاری ارائه نمی‌شود و پاسخ 405 می‌دهد. ابزارها:

| ابزار | عملکرد |
|---|---|
| `get_context` | دریافت شناسه سند، واحدها، لایه‌ها، اشیای انتخابی و اشیای اخیر همین پنل |
| `propose_plan` | اعتبارسنجی و نمایش طرح؛ نیازمند `document_id` فعلی و `plan` است |
| `get_plan_status` | خواندن وضعیت تأیید/اجرا و شناسه‌های واقعی خروجی |

کلاینت ابتدا `get_context` و سپس `propose_plan` را صدا می‌زند. تا کاربر داخل Rhino روی Apply نزند هندسه تغییر نمی‌کند. شناسه درخواست برگشتی برای `get_plan_status` استفاده می‌شود. خاموش‌کردن MCP توکن را باطل می‌کند؛ با هر روشن‌کردن توکن جدید صادر می‌شود. بستن پنل سرور آن را متوقف می‌کند.

**یک سرور ابری به localhost ویندوز دسترسی مستقیم ندارد.** برای Claude یا هر سامانه ابری باید کلاینت/پل روی همین رایانه اجرا شود. این بسته پل دسکتاپ دارد؛ تونل عمومی، میزبانی ابری و OAuth عمومی در این نسخه ارائه نشده است.

## عملیات هندسی و محدودیت‌ها

`create_building`, `create_box`, `create_line`, `create_polyline`, `create_curve`, `extrude_curve`, `move_object`, `scale_object`, `create_layer`, `select_objects`, `get_object_properties`.

همه پارامترها پیش از تغییر سند اعتبارسنجی می‌شوند. اجرای آزاد Python/C# یا کد تولیدشده توسط مدل وجود ندارد. طرح حداکثر ۱۰۰ عمل دارد؛ اشیای قفل، مخفی یا مرجع قابل تغییر نیستند. تغییر سند، واحد، tolerance یا هندسه هدف پس از پیش‌نمایش، طرح را نامعتبر می‌کند. لایه‌های جدید در یک سطح ساخته می‌شوند. عملیات جدید نمی‌تواند در همان طرح به شناسه شیء آینده اشاره کند؛ شناسه پس از اجرا مشخص می‌شود.

ابزار ساختمان، دال‌ها، ستون‌ها و نما را به اجزای جدا تقسیم و شماره طبقه و نقش هر جزء را ذخیره می‌کند. مدل یک ساختمان مفهومی است. بازسازی دقیق هر هندسه از هر تصویر، اتصال Grasshopper، حافظه پایدار پروژه و سیستم ورود/اشتراک کاربران، جزء این نسخه نیستند. مدل AI می‌تواند عملیات پشتیبانی‌شده را ترکیب کند؛ صحت مدل‌سازی همچنان در مرحله پیش‌نمایش و Apply بررسی می‌شود.

## ساخت سورس

وابستگی ساخت: SDK رسمی **.NET 8** روی Windows. با `-UseNuGet`، مرجع‌های نسخه مشخص SDK رسمی Rhino از NuGet دریافت می‌شوند و نصب محلی راینو برای کامپایل لازم نیست. اجرای هندسه و رابط همچنان به راینو با لایسنس معتبر نیاز دارد. بدون این گزینه، مرجع‌ها از نصب محلی Rhino خوانده می‌شوند.

```powershell
.\scripts\build.ps1 -UseNuGet
.\scripts\package.ps1
```

می‌توان `-DotNet` یا `-RhinoSystemDir` را برای مسیرهای متفاوت تعیین کرد. خروجی بسته‌بندی در `artifacts/releases` شامل Yak، نصب‌کننده ویندوز و SHA256 است. خط ساخت GitHub برای تمام سلوشن تنظیم شده و قالب GitLab در `ci/` قرار دارد؛ ایجاد تگ نسخه، پیش‌نویس Release قابل بررسی می‌سازد. کد در `src/ArchiTec.Core`، پلاگین در `src/ArchiTec.Rhino` و پل دسکتاپ در `src/ArchiTec.McpBridge` قرار دارد. طرح نمونه در `docs/box-plan.json` است؛ دکمه Plan JSON فایل را بدون اجرا پیش‌نمایش می‌کند.

## وضعیت اعتبارسنجی

ساخت سلوشن بدون خطا و هشدار انجام شده است. آزمون‌های هسته، HTTP/MCP و provider با پاسخ شبیه‌سازی‌شده اجرا شده‌اند. آزمون هندسه در خود Rhino شامل باکس، جابه‌جایی، واحد، پیش‌نمایش، extrusion، اشیای قفل و Undo بوده است. MCP واقعی با پنل و پل stdio نیز آزمایش شده است.

**در زمان تحویل، API Key شخصی ارائه نشده بود؛ پاسخ زنده OpenRouter/OpenAI و اتصال واقعی کلاینت Claude با حساب شما هنوز آزموده نشده است.** گزارش دقیق در `docs/VALIDATION.md` است. بسته برای انتشار در Yak/Food4Rhino آماده‌سازی شده و تا انتشار توسط مالک، نباید موجود در کاتالوگ عمومی فرض شود.
